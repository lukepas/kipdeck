03 The problem

23 minutes of nothing.

An agent that asks at 10:02 and is answered at 10:25 did nothing for 23 minutes. Vendors race to make agents faster, and each vendor's dashboard sees only its own agents. None of them shows how long your agents, across every vendor, sit blocked on you. {{name}} measures that.

04 The loop

Ask. Answer. Review. Merge.

The oldest agent waiting opens by itself. Its question is in plain words, with one reply box and a button per numbered choice, for every CLI. The finished diff sits beside the list. Merge on your machine without GitHub, or open a pull request.

  1. 1 / 4

    Ask

    The agent's raw terminal line becomes a card: the question in words, a button for each numbered choice.

  2. 2 / 4

    Answer

    One box. Send, and the wait stops counting. The agent goes back to work, then drops into To review.

  3. 3 / 4

    Review

    The real diff beside the list: the files, every hunk, the tests it ran.

  4. 4 / 4

    Merge

    On this computer, no GitHub needed, or as a pull request when gh is there.

06 Yours

One command. Your machine. A signed record.

It runs on your laptop or the team's dev box. {{name}} sends nothing anywhere: your agents talk only to their own model. Open source, MIT. Every merge and send-back is a signed record: the agent and model, who reviewed it, how long it waited.
