        Disclosure

        This page is read only and public. It shows outcomes that people caused on pull requests made by AI coding agents, as attested on Base Sepolia (EAS and ERC-8004) and paid on Solana devnet. Repository names show only for public repositories or where an office admin chose to show them; others read "a private repo", and some are left out. Each attestation on Base Sepolia is public and names its repository, pull request and merge commit, which is why the office attests public repositories only. Maintainers appear as a short keyed pseudonym from the attestation, not by name, though a merge commit on GitHub still shows who merged it. Nothing here is an offer, an investment or a promise of payment, and testnet tokens have no value.
