How it works

Built on an open-source, MIT-licensed shared workspace for coding agents. You can keep running it after the pilot at no license cost.

1

Set up on your repositories

A shared workspace on a VM in your cloud account, or on an EU-region VM we set up for you. Each engineer signs in with their own model and GitHub accounts. Branch protection stays on.

2

Agents take the queue

Well-scoped issues go into a task queue. Agents work in parallel, each on its own branch, and open pull requests. Everyone can watch or join any agent's terminal.

3

People review, we measure

Your engineers review every PR. Each week you get merged PRs, acceptance rate, review minutes and cost per merged PR, against your own baseline.

Security, plainly

Anyone who can sign in to an agent workspace can run commands through it. We design around that, rather than pretending otherwise.

  • One workspace per client, hosted in the EU or in your own cloud account.
  • Named accounts with roles, TLS everywhere, no public exposure without it.
  • Per-person model and GitHub sign-ins; we do not hold your API keys.
  • Agents never push to your default branch. Every PR is reviewed by your people.
  • Access revoked and data deleted at the end, confirmed in writing. DPA before any hosted pilot.

Questions

Which coding agents does it support?

Claude Code by default, with Codex, OpenCode and others available. You choose which providers may see your code.

Will this replace developers?

No. The work shifts toward writing good tasks and reviewing. The pilot measures how much review time each merged PR costs, because that decides whether it pays off.

What do you promise?

The setup, the documents and honest numbers. We agree goals at the start, such as acceptance rate and review minutes per PR, and report them at the end whether they were met or not. No productivity multiples.

What if our code cannot leave our network?

The workspace can run inside your network. The agents still call model APIs, so it needs a provider your policies allow. If none is allowed, start with the workshop on our practice repositories.
